JSON 格式说明

根节点可以是包含 problems 数组的对象，也可以直接是题目数组； 每道题必须包含 title 与至少一个 test_cases。 测试点的 input / output 需为字符串（换行写为 \n）。 

{
  "problems": [
    {
      "title": "A+B Problem",
      "description": "输入两个整数 a 和 b，输出它们的和。",
      "input_format": "一行，包含两个整数 a 和 b。",
      "output_format": "输出一个整数，表示 a + b。",
      "sample_input": "1 2\n",
      "sample_output": "3\n",
      "hint": "",
      "time_limit_ms": 1000,
      "memory_limit_kb": 65536,
      "is_visible": true,
      "test_cases": [
        { "input": "1 2\n", "output": "3\n" },
        { "input": "-5 7\n", "output": "2\n" }
      ]
    }
  ]
}
